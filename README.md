## About This Project

Created for FIT1050 Assignment 3. The Monash Future Science Society (MFSS) is a fictional student-led community for science students at Monash University, inspired by real Monash science societies but with all identifying information fictionalised.

## Tech Notes

- Base template: HTML5 UP Stellar (CCA 3.0) — preserved under `LICENSE.txt`
- Customisation: see `CUSTOMISATION.md` for palette, typography, layout, and JS feature deltas
- Image credits: see `IMAGE-CREDITS.md`
- Build (SCSS recompile): `bunx sass assets/sass/main.scss assets/css/main.css --style=compressed --no-source-map`
